### Effect kinds (abilities, boss phases)

| kind | fields |
| --- | --- |
| damage | stat (physPower\|magPower\|healPower\|defense\|maxHp), power, school (physical\|magical), hits?, executeBelow?, executeMult?, bonusCrit? |
| heal | stat, power |
| status | status, duration, stat?, power? (tick value), stacks?, chance?, self? |
| shield | stat, power, duration |
| taunt | duration |
| cleanse | count |
| resource | amount |
| summon | enemyId, count, max |

Procs (uniques/sets) can also use: `reflect` { pct } · `healPct` { pct } · `shieldPct` { pct, duration } · `cooldowns` { seconds }.

### Behaviour rules (defaultRule)

Conditions (`conditions[].type`):

| type | meaning |
| --- | --- |
| `always` | Whenever available |
| `self_hp_below` | Own health below |
| `self_hp_above` | Own health above |
| `ally_hp_below` | Any ally health below |
| `allies_below_hp` | Number of allies below health |
| `enemy_hp_below` | Any enemy health below |
| `enemies_alive` | Number of enemies alive |
| `allies_alive` | Number of allies alive |
| `self_has_status` | I have buff/debuff |
| `self_missing_status` | I am missing buff/debuff |
| `ally_has_status` | Any ally has buff/debuff |
| `enemy_has_status` | Any enemy has buff/debuff |
| `resource_above` | Resource above |
| `resource_below` | Resource below |
| `boss_present` | A boss is present |
| `combat_time_above` | Fight has lasted longer than |
| `own_minions` | Number of my minions |

Target conditions (`targetConditions[].type`):

| type | meaning |
| --- | --- |
| `alive` | Target must be alive |
| `target_missing_status` | Target must NOT have |
| `target_has_status` | Target must have |
| `target_has_debuff` | Target has any debuff |
| `target_hp_below` | Target health below |
| `target_hp_above` | Target health above |
| `target_role` | Target has role |
| `target_is_type` | Target is enemy type |
| `target_own_debuffs` | Number of my different debuffs on the target |
| `target_own_debuff_stacks` | Number of my debuff stacks on the target (every stack counts) |
| `target_is_minion` | Target is a minion |

Target selectors (`target.selector`):

| selector | meaning |
| --- | --- |
| `self` | Self |
| `ally_lowest_hp_pct` | Ally with lowest health % |
| `ally_lowest_hp` | Ally with lowest health |
| `ally_highest_hp_pct` | Ally with highest health % |
| `ally_random` | Random living ally |
| `ally_tank` | Ally tank (fallback: lowest health %) |
| `all_allies` | All allies |
| `own_minions` | All my minions |
| `own_minion_lowest_hp` | My minion with lowest health % |
| `enemy_current` | Current target (front-most enemy) |
| `enemy_lowest_hp_pct` | Enemy with lowest health % |
| `enemy_lowest_hp` | Enemy with lowest health |
| `enemy_highest_hp` | Enemy with highest health |
| `enemy_highest_threat` | Enemy with highest threat |
| `enemy_random` | Random enemy |
| `enemy_type` | Specific enemy type |
