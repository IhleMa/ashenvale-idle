### Effect kinds (abilities, boss phases)

| kind | fields |
| --- | --- |
| damage | stat (physPower\|magPower\|healPower\|defense\|maxHp), power, school (physical\|magical), hits?, executeBelow?, executeMult?, bonusCrit? |
| heal | stat, power |
| status | status, duration, stat?, power? (tick value), stacks?, chance?, self? |
| shield | stat, power, duration |
| taunt | duration |
| cleanse | count |
| resource | amount |
| summon | enemyId, count, max |

Procs (uniques/sets) can also use: `reflect` { pct } · `healPct` { pct } · `shieldPct` { pct, duration } · `cooldowns` { seconds }.
