# Put your game art here

Drop images into the sub-folders using the entity id as the file name, e.g. `enemies/wolf.png`,
`items/sword.png`, `abilities/fireball.png`, `classes/warrior.png`.

The complete list of names is in **ASSETS.md** at the root of the repository (`npm run assets` regenerates it).
Missing images show a generated placeholder. Refresh the browser after adding files — no restart required.
